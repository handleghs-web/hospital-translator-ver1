# 🏥 병원용 양방향 동시통역 PWA 웹앱 (v2 수정판)

## 📌 주요 수정 사항
1. **언어 지정 위치 변경 및 글씨 크기 확대**:
   - 기존 환자 영역 내부에 있던 언어 드롭다운을 **상단 헤더(병원명 바로 옆)**로 이동
   - 라벨 및 드롭다운 글씨 크기를 대폭 확대하여 직관적이고 빠르게 변경 가능하도록 개선
2. **마이크 버튼 위치 변경 (안드로이드 표시줄 짤림 방지)**:
   - 2000*1200 해상도 태블릿 하단 표시줄/소프트키 간섭을 차단하기 위해 **마이크 버튼을 카드 상단 타이틀 우측(의료진/환자 각각 옆)**으로 이동
   - 대화 출력창이 하단 끝까지 시원하게 확장됨
